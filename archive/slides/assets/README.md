# Assets dos slides

## brasao-ufc.png (pendente)
Baixe o brasão oficial no Manual de Identidade Visual da UFC e salve aqui como
`brasao-ufc.png` (fundo transparente, ~240px):
https://www.ufc.br/a-universidade/identidade-visual-da-ufc

Enquanto o arquivo não existir, os slides de capa/créditos mostram um placeholder.
O `<img>` cai para o placeholder automaticamente via `onerror`.
